## 用户权限

**1. 请说明 chmod 777 中三个数字各代表什么含义，并解释为什么在生产环境中应慎用 777 权限。**
【评分要点】评分要点：三组对象与 7 的构成答对给 6 分；说清至少一条具体风险给 2 分；提到最小权限原则给 2 分。
答：参考答案：三个数字依次表示所有者、所属组、其他用户的权限；7 = 读(4) + 写(2) + 执行(1)，即所有人可读、可写、可执行。慎用原因：任意用户都能改写甚至替换文件，存在被篡改、植入恶意脚本和误删的风险，应遵循最小权限原则按需授权。

## Linux 基础

**3. 为什么服务器操作系统基本都使用 Linux？**
答：目前约99%的服务器操作系统使用Linux，常见应用（百度、Google、豆包、抖音、微信等）都部署在Linux之上，此外Linux还广泛用于嵌入式（如公交系统）。

**4. Linux 内核是谁开发的？什么时候开始？**
答：由林纳斯·托瓦兹（Linus Torvalds）于1991年开始开发并首次发布，采用开放协作方式持续演进，是类Unix操作系统内核。

**5. 什么是 GPL？其核心原则是什么？**
答：GPL全称GNU General Public License（GNU通用公共许可证），由Richard Stallman为GNU项目编写。核心原则：允许用户自由运行、复制分发、修改软件，但衍生作品也必须以GPL许可证发布。

**6. Linux 发行版分为哪两大系？各代表哪些系统？**
答：红帽系（RedHat→RHEL企业版，CentOS社区版，Rocky，Fedora，麒麟，openEuler）和Debian系（Debian→Ubuntu、SUSE、UOS）。

**7. RedHat、CentOS、Rocky 三者的关系？**
答：红帽将CentOS收购，CentOS 8以后维护不及时；Rocky由CentOS原作者基于CentOS再次创业，作为社区免费的RHEL替代。开发流程：Fedora（开发版）→ CentOS（测试）→ RedHat主线。

**8. 完整的操作系统由哪两部分组成？**
答：用户态和内核态。用户态提供GUI图形界面和shell命令，内核负责调用硬件层（CPU、内存、磁盘）。

**9. 解释命令提示符 `[root@bogon ~]#` 各部分的含义。**
答：格式为`[用户@主机名 所在位置] 提示符`。root为当前用户，bogon为主机名，`~`表示家目录，`#`表示超级管理员（普通用户提示符为`$`）。

**10. Linux 操作系统的哲学是什么？**
答：一切皆文件；Linux是多用户的操作系统。

**11. Linux 命令的基本语法格式是什么？**
答：`命令 [选项] [参数]`，中括号表示可有可无。获取帮助可用`命令 -h`或`man 命令`。

**12. `ls` 命令的 `-a` 和 `-l` 选项分别是什么作用？**
答：`-a`列出所有文件（包含以`.`开头的隐藏文件）；`-l`以长格式输出文件详细信息。`ll`等价于`ls -l`。

**13. Linux 中以什么开头的文件是隐藏文件？**
答：以`.`（点）开头的文件称为隐藏文件。

**14. Linux 的重启和关机命令分别有哪些？**
答：重启：`reboot`、`init 6`；关机：`init 0`、`halt`。

**15. 写出 init 0~6 各运行级别对应的含义。**
答：0关机；1单用户模式（救援）；2多用户模式（无网络）；3字符界面（多用户文本模式）；4保留；5图形界面；6重启。

**16. `hostname` 和 `hostnamectl set-hostname` 修改主机名有什么区别？**
答：`hostname 124-class.com`是临时修改（Transient hostname），重启失效；`hostnamectl set-hostname`是永久修改（Static hostname）。修改后可用`bash`刷新环境验证。

**17. `pwd`、`exit`、`date`、`clear`、`history` 分别是什么作用？**
答：pwd打印当前工作目录；exit退出终端或用户；date查看系统时间；clear清除屏幕（快捷键Ctrl+L）；history查看历史命令。

**18. `su` 和 `su -` 有什么区别？**
答：`su`仅切换用户身份；`su -`切换用户并连同该用户的家目录环境一起切换（更推荐）。

**19. `who`、`whoami`、`w` 三个命令的区别？**
答：who显示当前已登录的用户信息；whoami显示与当前有效用户ID关联的用户名；w显示当前登录用户信息及其执行的命令，还包括系统时间、运行时长、平均负载等。

**20. `wc` 命令的 `-c`、`-m`、`-l` 选项分别是什么？**
答：`-l`打印行数，`-m`打印字符总数，`-c`打印字节总数（中文等多字节字符下字节数与字符数不同）。

**21. `uname -a` 的作用是什么？如何通过文件查看系统版本信息？**
答：`uname -a`输出内核名称、主机名、内核版本、发行号、硬件架构等所有系统信息；也可通过`cat /etc/os-release`查看操作系统版本。

**22. `echo` 与重定向符号 `>`、`>>` 的区别？**
答：echo为标准输出；`>`是重定向输出，覆盖原文件所有内容；`>>`是重定向追加，在文件末尾追加新内容。

## Linux 基础 - 02

**23. `mkdir -p` 的作用？`rm -r`、`rm -f` 的作用？**
答：`mkdir -p`递归创建多级目录（如`mkdir -p ac/b/c/d/e`）；`rm -r`递归删除目录及目录内所有文件；`rm -f`强制删除不提示。删除操作要三思而后行，Linux没有后悔药。

**24. `cp` 和 `mv` 命令的区别？**
答：cp是拷贝文件（源文件保留）；mv是移动文件，也可用于修改文件名称（如`mv ac ca`）。

**25. `cat`、`more`、`less`、`tail` 查看文件各有什么特点？**
答：cat一次性输出全部内容（`-n`显示行号）；more以页显示，回车滚动一行、空格翻页；less分屏上下翻页浏览，q退出；tail默认显示文件末尾10行。

**26. `tail -f` 的作用是什么？管道符 `|` 的作用？**
答：`tail -f`动态观察文件内容变化（常用于看日志）；管道符`|`把前一个命令的输出作为后一个命令的输入，如`tail xxx | wc -l`统计行数。

**27. `cd` 命令中 `~`、`-`、`.`、`/`、`..` 分别表示什么？**
答：`~`用户家目录；`-`返回上次所在的工作目录；`.`当前目录；`/`系统根目录；`..`上一级目录。

**28. 相对路径与绝对路径的区别？**
答：相对路径：在当前目录下访问当前目录下的文件（不以/开头）；绝对路径：以根`/`作为起始访问目录（如`cd /dev/block/`）。分为两种访问策略是为了安全。

**29. `ifconfig` 与 `ip address` 查看网卡有什么区别？`nmcli` 是什么？**
答：ifconfig是最小安装中默认没有的命令，需独立安装；`ip ad`（可缩写）所有类unix系统都支持。nmcli是NetworkManager网络管理器的命令行工具，可`nmcli connection show`查看连接、`nmcli connection up/down ens160`启停网卡。

## 用户与组管理

**30. Linux 中用户分为哪三类？**
答：超级用户root（UID=0）；普通用户（UID≥1000，可登录）；系统/伪用户（UID 1~999，不能登录，为系统进程或服务如nginx、mysql运行所需）。

**31. `useradd` 命令常用选项有哪些？**
答：`-s`指定用户shell环境（如`-s /sbin/nologin`禁止登录）；`-M`不创建家目录；`-r`创建系统账户；`-u`指定UID；`-e`设置账户过期日期。

**32. `id` 命令的输出如何解读？**
答：uid=用户ID，gid=主组ID，groups=附加组。系统判断权限不以用户名而是以UID。

**33. `/etc/passwd` 文件每行七个字段分别是什么？**
答：用户名、密码占位符x、UID、GID、用户描述、家目录、是否可使用bash环境（如`/bin/bash`或`/sbin/nologin`）。

**34. `/etc/shadow` 中第三、四、五字段分别表示什么？**
答：第三字段是最近改动密码的日期（从1970年1月1日算起的天数）；第四字段是密码不可被变更的天数（0无限制）；第五字段是密码需要重新变更的天数（99999为无限制）。

**35. `passwd` 命令的作用？**
答：设置/修改用户密码；不带参数默认修改当前登录用户的密码。普通用户无权修改root用户密码。

**36. `usermod` 命令的作用？如何修改用户登录名？**
答：usermod修改用户属性，如`usermod -l 新用户名 旧用户名`修改登录名；`usermod -g A lisha`修改用户主组。

**37. 用户与组的对应关系有哪四种？组的配置文件有哪些？**
答：一对一、一对多（一个用户属于多个组）、多对一（多个用户属于一个组）、多对多。组配置文件：`/etc/group`（组名、密码占位符、GID）；组密码文件：`/etc/gshadow`。组管理命令：groupadd/groupmod/groupdel。

## 权限管理

**38. `ll` 输出的第一列如 `drwxr-xr-x.` 如何解读？**
答：第一个字符是文件类型（d目录、-普通文件、b块设备、l链接文件、c字符设备），后面九个字符每三个一组：所有者rwx、组rwx、其他用户rwx。第二列是链接数，之后是所有者、主组、大小、修改时间、文件名。

**39. r、w、x 权限的数字表示方式是什么？**
答：r(read)=4，w(write)=2，x(execute)=1，无权限=0。如rwx=7，r-x=5。

**40. `chmod` 命令如何使用？举两个例子。**
答：语法`chmod [模式] 文件`。例：`chmod u=rwx wa`给所有者设rwx；`chmod 666 wa`以数字方式设置所有者、组、其他均为rw-；`chmod u-x wa`删除所有者的x权限。

**41. `chown` 命令的作用和语法？**
答：修改文件所有者和组。`chown xiaoli wa`改所有者；`chown :A wa`改主组；`chown abbott:abbott wa`同时改所有者和主组。

**42. 什么是 ACL（访问控制列表）？作用是什么？**
答：ACL（Access Control List）用于对文件或目录给特定用户/组设定权限，突破"所有者/组/其他"三组权限的限制。

**43. `setfacl` 命令的常用模式有哪些？`getfacl` 的作用？**
答：`-m`设置ACL权限（如`setfacl -m user:abbott:rwx file`）；`-x`移除指定用户的ACL；`-b`移除所有ACL。getfacl用于查看文件的ACL权限。

**44. 什么是 SUID（user+s）特殊权限？针对什么文件？**
答：SUID针对可执行文件，设置后执行该文件时以文件所有者的身份运行（如`/usr/bin/passwd`显示-rwsr-xr-x）。若文件不可执行则显示大写S。

**45. 什么是 SGID（group+s）特殊权限？**
答：针对目录设置，可实现子目录继承父目录的"组"属性，常用于团队共享目录。

**46. 什么是粘滞位（other+t）？典型例子是什么？**
答：粘滞位设在目录上，限制文件删除——只有文件所有者和root能删除该目录中的文件，其他用户只能读/写自己的文件。典型例子是/tmp目录（drwxrwxrwt）。

**47. `sudo` 命令的作用？其配置文件是什么？**
答：sudo用于临时提权执行命令（如`sudo vim /etc/passwd`），配置文件为`/etc/sudoers`，可为指定用户（如`xiaobai ALL=(ALL) ALL`）或组（如`%wheel ALL=(ALL) ALL`）配置权限。

## 磁盘管理与 LVM

**48. 机械硬盘与固态硬盘各有什么特点？**
答：机械盘数据安全性高、寿命长、速度慢，用于共享存储（存储柜）、备份数据（也可用磁带，存放时间更长）；固态盘速度快，用于系统层和常用数据（缓存层）。

**49. Linux 磁盘设备的命名规则是什么？**
答：SATA/SCSI磁盘为sda、sdb、sdc（a/b/c表示第几块硬盘）；NVMe协议（m.2）为nvme0n1；虚拟磁盘为vda、vdb、vdc。分区在磁盘名后加数字：sda1第一分区、sda2第二分区。Windows用C/D/E盘符。

**50. `fdisk` 命令的作用？交互中 n、p、d、w 分别是什么？**
答：fdisk是交互式分区管理工具，能识别GPT、MBR、Sun、SGI、BSD分区表。`fdisk -l`列出分区信息；交互中n创建新分区、p打印分区情况、d删除分区、w保存并退出。

**51. `parted` 与 `fdisk` 相比有什么优缺点？**
答：parted是GNU开发的分区工具，支持大于2TB磁盘、支持128个主分区（fdisk只支持4个主分区）、支持调整分区大小；缺点是"没有三思而后行"——不驻留内存直接操作磁盘。支持交互式和命令行两种方式。

**52. Linux 新磁盘投入使用的基本流程是什么？**
答：物理磁盘 → 新建分区（fdisk/parted）→ 格式化文件系统（mkfs.ext4/mkfs.xfs）→ 创建挂载点（mkdir）→ 挂载（mount 源 挂载点）。

**53. 什么是文件系统？常见的文件系统有哪些？**
答：文件系统是操作系统管理存储设备上数据存储、组织和访问的核心机制，将用户文件映射到物理存储并提供统一访问接口。Linux常用Ext4、XFS，Windows用NTFS；exFAT优点是所有操作系统可写、支持大于4GB的文件传输。

**54. 什么是 inode 和 dentry？**
答：inode（索引节点）唯一标识每个文件，记录文件大小、权限、创建/修改时间及数据在磁盘上的位置；dentry（目录项）记录文件名及其与inode的关联关系，形成目录结构。

**55. `lsblk` 和 `df -h` 的区别？**
答：lsblk列出块设备的层级结构（磁盘→分区→LVM）及挂载点；`df -h`以人类可读单位显示文件系统的容量、已用、可用、使用百分比和挂载点。

**56. `mount` 和 `umount` 的作用？**
答：mount将分区挂载到挂载点目录（如`mount /dev/sdb2 /test02`）；umount卸载文件系统（删除分区前需先检查并卸载）。

**57. MBR 与 GPT 分区表的主要区别？**
答：MBR最大支持2TB磁盘、最多4个主分区（或3主+1扩展）、搭配传统BIOS、仅一份分区记录易丢数据、兼容老系统；GPT支持超大容量（理论9.4ZB）、最多128主分区、必须搭配UEFI（Windows11强制）、有主备分区表双重冗余和CRC校验。Linux默认使用MBR。

**58. 什么是 LVM？PV、VG、LV 分别是什么？**
答：LVM（逻辑卷管理器）是硬盘和分区之上的软件虚拟层，支持动态卷大小调整、不停机换盘、快照备份等。PV物理卷：将物理磁盘或分区创建为物理卷；VG卷组：将多个物理卷组成存储池；LV逻辑卷：从VG中划分出的可格式化挂载的分区。PE是LVM的最小存储单元（默认4MB）。

**59. LVM 的创建流程及相关命令？**
答：`pvcreate /dev/sda /dev/sdb`创建物理卷 → `vgcreate myvg /dev/sda /dev/sdb`创建卷组 → `lvcreate -L 5G -n mylv myvg`创建逻辑卷 → `mkfs.ext4 /dev/myvg/mylv`格式化 → mount挂载。查看命令：pvdisplay/vgdisplay/lvdisplay（简写pvs/vgs/lvs）；删除：pvremove/vgremove/lvremove。

**60. LVM 扩容如何操作？ext4 和 xfs 刷新命令有何不同？**
答：`lvextend -L +15G myvg/mylv`增加15G（或`-L 20G`扩到20G），然后刷新文件系统：ext4用`resize2fs /dev/myvg/mylv`；xfs用`xfs_growfs 挂载点`。

**61. 如何实现开机自动挂载？**
答：修改`/etc/fstab`，格式为：文件系统 挂载点 文件系统类型 权限(defaults) 0 0（可用UUID=xxx代替设备名，UUID通过`blkid`获取）。修改后用`mount -a`验证书写无误，再reboot验证。

## 软件包与服务管理

**62. Linux 安装软件包的方式有哪些？**
答：二进制包（RPM，类似Windows的exe）、源码包（需自己编译，高级语言→编译器→机器语言）、YUM/DNF在线安装（红帽系）或apt（Debian系）。

**63. `rpm` 常用选项有哪些？**
答：`-i`安装，`-ivh`安装并显示进度和详细信息；`-q`查询是否已安装（`rpm -q tree`）；`-e`卸载；`-ql`列出软件包中的文件/查询包的文件清单。

**64. RPM 的核心功能是什么？**
答：通过本地数据库记录软件的安装、卸载和依赖关系：安装与卸载、查询与校验、依赖管理（复杂依赖由上层YUM/DNF处理）。

**65. YUM/DNF 的作用？与 RPM 的关系？**
答：YUM/DNF是基于rpm的软件包管理器，能从指定服务器自动下载RPM包并安装、自动处理依赖关系并一次装齐。RHEL7以下只能用YUM，8+两个命令都可用。

**66. YUM 源配置文件在哪？基本字段有哪些？**
答：配置文件位于`/etc/yum.repos.d/`，文件命名`源名称.repo`。字段：[源id]（随便写）、name=描述、baseurl=仓库地址（http://、file://等）、gpgcheck=1|0（验证包完整性）、enabled=1|0（是否启用）。Debian系网络源配置在`/etc/apt/sources.list`。

**67. 配置本地镜像源的基本步骤？**
答：挂载本地镜像`mount /dev/sr0 /mnt/` → 备份原有网络源（mv到备份目录）→ 在`/etc/yum.repos.d/local.repo`中写baseurl=file:///mnt/AppStream和file:///mnt/BaseOS → `yum clean all`清缓存 → `dnf search/install`验证。

**68. `systemctl` 管理服务的常用子命令？**
答：`systemctl start 服务`启动、`stop`停止、`status`查看状态、`restart`重启、`reload`重载、`enable`加入开机自启（`enable --now`立即启动并自启）。如防火墙：`systemctl stop firewalld`。

**69. tar 命令的常用选项？**
答：`-c`创建归档、`-x`解压、`-t`列出归档内容、`-f`指定归档文件、`-v`显示详细过程、`-C`指定解压目标目录。如`tar xf xxx.tar.gz -C /usr/local/`。

## 服务器监控与进程管理

**70. 查看主板、磁盘、内存、CPU 的命令分别有哪些？**
答：主板lspci；磁盘df -h、lsblk、fdisk -l；内存free -h、lsmem、cat /proc/meminfo；CPU lscpu；网卡流量ifstat。

**71. `free -h` 输出中 total、used、free、available、buff/cache 各是什么？**
答：total总内存与Swap；used已使用；free剩余；buff/cache缓冲/缓存；available实际可使用的内存。Swap是交换分区（从硬盘划出，内存不够时使用，生产环境一般关闭）。

**72. `df -h` 输出的六列分别是什么？**
答：文件系统、总容量、已用容量、可用容量、使用百分比、挂载点。

**73. `ps -aux` 输出的关键字段含义？**
答：USER所属用户、PID进程ID、%CPU占用CPU百分比、%MEM占用内存百分比、VSZ虚拟内存、TTY伪终端、STAT进程状态、START启动时间、TIME占用CPU时间、COMMAND命令。

**74. ps 中 STAT 的常见状态有哪些？**
答：S睡眠状态；R运行状态；T停止/侦测状态；Z僵尸（进程已终止但父进程未正常回收）。

**75. `top` 命令第一行的信息如何解读？**
答：`top - 时间 up运行时长, 用户数, load average: 1分/5分/15分平均负载`。第二行Tasks显示任务总数及running/sleeping/stopped/zombie数量。

**76. top 中 us、sy、id、wa 各代表什么？**
答：us用户态使用CPU；sy系统态使用CPU；id空闲时间；wa等待I/O完成的时间。此外ni进程优先级、hi硬件中断、si软件中断、st被hypervisor占用的时间。

**77. `ss` 和 `netstat` 命令的作用？常用选项？**
答：显示处于活动状态的套接字/网络状态信息。常用：`-l`显示监听套接字、`-t`TCP、`-u`UDP、`-n`不解析服务名、`-p`显示使用套接字的进程。如`ss -luntp`、`netstat -luntp`。

**78. `kill` 与 `pkill` 的区别？**
答：kill按PID给指定进程发送终止信号（如`kill 141518`）；pkill按进程名称杀所有相关进程（含父进程和子进程，如`pkill sshd`会断开自身ssh连接）。

**79. 后台任务如何操作？**
答：命令后加`&`放到后台运行；快捷键Ctrl+Z将当前任务放到后台（暂停）；`jobs`查看后台任务；`fg [任务编号]`将任务调度回前台。

## 计算机网络

**80. IP 地址分哪几类？各类的范围和掩码？**
答：A类：1.0.0.0~126.255.255.255，掩码255.0.0.0；B类：128.0.0.0~191.255.255.255，掩码255.255.0.0；C类：192.0.0.0~223.255.255.255，掩码255.255.255.0；另有D、E类。

**81. IP 地址中 0、255、1、254 的特殊用途？**
答：0作为网段地址；255作为广播地址；1和254通常作为网关地址；主机可用范围是2~253。IP作为计算机通信的地址，取值0-255但去掉0和255。

**82. 127.0.0.1 的作用？**
答：本机回环地址（127.0.0.0~127.255.255.255为保留段），用于测试本机网络协议是否正常，对应Linux的lo网卡。

**83. 子网掩码的作用是什么？如何计算网段？**
答：子网掩码用于验证两个IP是否属于同一网段。计算：IP与掩码逐位与运算，如1100 0000.1010 1000.0001 0010.0000 1010 与 255.255.255.0 与运算得 192.168.18.0。

**84. IPv6 与 IPv4 的区别？**
答：IPv4为32位（如192.168.18.10），地址池早已用完；IPv6为128位，可以让世界上每个分子都有一个公网IP地址，如fe80::ff67:3574:7bb1:9e8a%10。

**85. 交换机的作用是什么？MAC 地址是什么？**
答：交换机（Switch）是一种用于电（光）信号转发的网络设备，为接入的任意两个网络节点提供独享通路；其数据交换基于MAC地址表，存放每个节点（主机）的MAC地址。MAC地址是计算机网卡（wifi/以太网卡）的"身份证"。查看命令：`display mac-address`。

**86. 路由器的作用是什么？**
答：实现地址转换NAT（网络地址转换），并维护路由表，实现不同网段间的通信。查看路由表：`display ip routing-table`。

**87. 华为设备如何进入系统视图？常用查看命令？**
答：`<Huawei>system-view`（简写sys）进入系统视图`[Huawei]`；`display interface`查看接口信息；`interface Ethernet 0/0/1`进入接口；`shutdown`/`undo shutdown`关闭/启用接口；`quit`退出。

**88. 静态路由如何配置和删除？**
答：添加：`ip route-static 目标网段 掩码 下一跳`，如`ip route-static 192.168.18.0 255.255.255.0 10.10.10.1`；删除：`undo ip route-static 192.168.18.0 255.255.255.0 Ethernet 0/0/1`；验证：`display ip routing-table`。

**89. TCP 与 UDP 的区别？**
答：UDP不建立连接、不安全但速度快；TCP慢但安全，有重传机制，通过三次握手建立连接、四次挥手断开连接。

**90. TCP/IP 四层模型和 OSI 七层模型分别是什么？**
答：TCP/IP四层：应用层、传输层、网络层、链路层；OSI七层：物理层、数据链路层、网络层、传输层、会话层、表示层、应用层。OSI五层模型基本不使用。

**91. 什么是 MTU？**
答：MTU（最大传输单元）是网络能够传输的最大数据包大小，以字节为单位，默认以太网1500字节。过大导致报文分片甚至丢弃，过小则传输效率低。

**92. 网络实验常用哪些模拟器和抓包工具？**
答：思科模拟器Cisco Packet Tracer 8.2.1，华为模拟器ensp，抓包工具wireshark。ensp安装后需在防火墙中允许其访问外部网络。

## Nginx 与 Web 服务

**93. 什么是 URL？其组成部分有哪些？**
答：URL（统一资源定位符）是互联网上标识特定资源的唯一地址。组成：协议（http/https/ftp/file）、主机名/域名、路径、查询字符串（?开头）、片段标识符（#开头）。

**94. HTTP 与 HTTPS 的区别？**
答：HTTP明文传输不安全，端口80；HTTPS加密传输，端口443（另有8443）。Web服务基于TCP/IP协议，应用层协议为HTTP/HTTPS。

**95. 常见的 Web 中间件有哪些？**
答：Httpd（Apache基金会）、Nginx（俄罗斯）、Caddy、OpenResty、Tomcat（Java）、WebLogic（Oracle）。

**96. Nginx 的主要功能是什么？**
答：Nginx是一个Web服务器，支持负载均衡、TCP/UDP协议代理、缓存、代理Email服务器，开源、基于模块化的web服务。Nginx本身不能跑Java代码（Tomcat才能）。

**97. Nginx 虚拟主机有哪三种配置方式？**
答：基于端口（listen 81/82/83）、基于IP地址（listen 192.168.110.138:80，需要多个IP/网卡）、基于域名（server_name 124class.com，客户端通过/etc/hosts解析）。

**98. Nginx 主配置文件的结构？**
答：三大部分：全局模块（user、worker_processes、error_log、pid）→ events事件驱动块（worker_connections 1024）→ http模块（日志格式、include conf.d/*.conf，内含多个server虚拟主机）。

**99. Nginx 常用管理命令有哪些？**
答：`nginx -v`显示版本；`nginx -V`显示版本及configure编译参数（升级需保留原模块）；`nginx -t`测试配置语法；`nginx -s reload`热加载（用户无感知）、stop暴力停止、quit温柔停止、reopen重新打开日志。

**100. Nginx 反向代理如何配置？**
答：在server块的location中使用`proxy_pass`，如`location / { proxy_pass http://192.168.18.20; }`。正向代理位于客户端前（访问控制/匿名），反向代理位于服务器前（负载均衡/缓存/隐藏真实服务器）。

**101. Nginx 负载均衡的调度算法有哪些？**
答：默认轮询RR（round-robin轮流分发）；least_conn最少连接（分给活跃连接最少的服务器）；ip_hash根据客户端IP哈希确定服务器（保持会话）；weight权重（如`server 192.168.18.20 weight=3;`加权轮询）。upstream中还可设max_fails健康检查、backup备份节点、down节点下线。

**102. 证书 DV、OV、EV 的区别？如何生成自签证书？**
答：三者加密强度一样，区别在身份核验严格程度：DV仅核验域名所有权（免费证书多为DV）；OV核验域名+企业资质；EV最高等级核验（银行/支付使用）。自签证书：`openssl genrsa -out private.key 2048`生成私钥 → `openssl req -new -key private.key -out certificate.csr`生成CSR → `openssl x509 -req -days 3650 -in certificate.csr -signkey private.key -out certificate.crt`自签证书。自签证书互联网不认可，仅限局域网使用。

## Tomcat、MySQL、Redis

**103. Tomcat 是什么？与 Nginx 的区别？**
答：Tomcat是轻量级的Web容器（Servlet容器），用来运行Java Web项目（Servlet、JSP、SpringBoot war包），Apache出品。区别：Nginx是C语言写，做静态资源、反向代理、负载均衡，本身不能跑Java代码；Tomcat是Java写的，专跑Java程序，但并发和静态处理不如Nginx。

**104. Tomcat 的默认端口有哪些？**
答：8080用户访问端口；8005管理员（关闭）端口；8443为Java应用的HTTPS端口。Tomcat需要先安装JDK（如`dnf install java-17-openjdk`），通过`java --version`验证。

**105. HTTP 状态码 2xx/3xx/4xx/5xx 的含义及常见码？**
答：2xx成功：200 OK、201 Created、204无内容；3xx重定向：301永久重定向、302临时跳转、304走浏览器缓存；4xx客户端错误：400请求格式错误、401需要认证、403拒绝访问、404资源不存在；5xx服务器错误：500内部错误、502/503/504网关问题。

**106. 什么是数据库？关系型与非关系型数据库的区别？**
答：数据库是按照数据结构来组织、存储和管理数据的电子仓库。关系型：数据与数据之间有关联（A表→B表），如MySQL、PostgreSQL、达梦、金仓；非关系型：数据无关联、键值对关系，如Redis、MongoDB。

**107. SQL 语句分为哪几类？各代表什么命令？**
答：DDL数据定义语言（CREATE、ALTER、DROP、TRUNCATE）；DML数据操作语言（INSERT、UPDATE、DELETE）；DQL数据查询语言（SELECT）；DCL数据控制语言（GRANT、REVOKE）；TCL事务控制语言。SQL语句以`;`结束。

**108. MySQL 常用基础操作命令？**
答：登录`mysql -uroot -p`（-u指定用户，-p指定密码）；`show databases;`查看所有库；`create database db01;`建库；`drop database db01;`删库；`use db01;`进入库；`show tables;`看表；`create table student(id int);`建表；`select * from 表;`查数据。MySQL默认端口3306。

**109. 什么是缓存？Redis 是什么？**
答：缓存是用于加速数据访问的临时存储机制，核心思想是"空间换时间"。分类：硬件级（CPU L1/L2/L3）、本地缓存、分布式缓存（Redis、Memcached）、网络与客户端缓存（浏览器缓存、CDN）。Redis是基于内存的键值对NoSQL数据库，支持分布式缓存和消息队列，支持数据持久化。

**110. Redis 的默认端口、常用管理命令和持久化方式？**
答：默认端口6379，默认16个库（0~15）。命令：redis-server启动（可指定redis.conf）、redis-cli客户端登录、ping返回PONG、set/get存取key、EXPIRE设置过期、TTL查看剩余秒数、INFO查看服务信息、FLUSHDB/FLUSHALL清库（高危）。持久化两种方式：RDB定时快照到硬盘，AOF记录每次写命令，通常结合使用。
