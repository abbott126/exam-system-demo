# 考试系统（v1.0 正式版）

**版本：v1.0 正式版 · 发布日期：2026-10-31**（发布说明见 `版本说明.md`）

按《考试系统Demo-PRD.md》v1.0 开发，主线全流程已跑通：
**教师建题 → 组卷（手动 / 规则随机）→ 发布考试 → 学生答题 → 自动判分 → 成绩统计 / CSV 导出**。

## 快速启动

环境要求：Node.js 18 及以上（无需安装任何第三方包，无需数据库）。核心考试流程断网可用；编程题中的 Python 题需要本机有 `python3` 命令（JavaScript 题用 Node 自身判题）；AI 功能需要能访问所配置的模型接口（云端需联网，本机 Ollama 不需要）。

一键启动：Windows 双击 `start.bat`（会自动打开浏览器）；macOS / Linux 运行 `./start.sh`。或手动启动：

```bash
node server.js
```

浏览器打开 http://localhost:3000 即可。换端口：`PORT=8080 node server.js`。

### 容器运行（Docker）

镜像基于 `node:22-alpine`，已内置 Python 判题所需的 `python3` 与时区数据，无需在宿主机装 Node/Python：

```bash
docker compose up -d --build   # 构建并后台启动，访问 http://localhost:3000
docker compose logs -f         # 看日志
docker compose down            # 停止（数据保留）
```

要点：

- 数据（`db.json`）存放在命名数据卷 `exam-data` 中，容器重建/升级不丢数据；想恢复初始演示数据：`docker compose down -v` 后重新 `up`。
- 时区已设为 `Asia/Shanghai`（考试时间窗口按本地时间锚定）。
- Compose 的 3000 端口默认发布到宿主机所有网络接口；编程题判题未做系统级沙箱隔离，只应在可信、隔离的演示网络使用，勿做端口转发或暴露公网。
- 不用 Compose 也可以：`docker build -t exam-system:1.0 .` 后 `docker run -d --name exam-system -p 3000:3000 -v exam-data:/app/data exam-system:1.0`。

首次启动会自动生成演示数据到 `data/db.json`；想恢复到初始演示状态，停掉服务后删掉该文件再重启即可。

## 已实现功能（对应 PRD 章节）

- 4.1 登录与角色权限：教师只能管自己的题目/试卷/考试；学生只能看自己的答卷；答题接口不下发正确答案
- 4.2 题库管理：四种题型的新增、编辑、删除，按题型/难度/关键词筛选
- 4.2 判分口径：单选/判断对错判分；多选全对满分、漏选按比例、含错选 0 分；填空去空格精确匹配、多空按空给分、支持 `|` 分隔的等价答案
- 主观题与人工阅卷（PRD 第 9 节提前落地）：新增简答题型（参考答案 + 评分要点）；交卷后客观题先出分，简答题进入教师待批改队列（统计页有待批改区，考试列表有计数提醒）；教师对照参考答案与评分要点逐题给分、写评语，总分自动更新；批改完成前学生成绩显示"暂定/待批改"，统计与排名只计已批改完成的答卷；分数分布与及格率按得分率折算（兼容非 100 分试卷）
- 错题本与重练：学生答错/未满分的题目自动收录（限开启答案展示的考试），可在线重练即时判分，答对自动移出，也可手动移出；简答题对照参考答案自查
- 批量导入导出：题库支持 CSV 批量导入（附模板，逐行校验、错误行清单返回）与 CSV 导出；管理员支持 CSV 批量导入学生（重复账号自动跳过）
- 考试防作弊增强：发布考试可设"切屏次数上限"（0 = 不限制），学生切屏超限自动交卷（前端拦截 + 服务端保存进度时兜底），统计页标注交卷原因（切屏超限/到时/手动）
- 试卷打印：试卷可生成学生版（无答案，含姓名/班级/得分栏）与教师版（带答案解析）的打印页
- 账号与数据安全：所有角色可自助修改密码（侧边栏入口）；管理员可导出全量备份（JSON）、从备份恢复（恢复后需重新登录）；登录接口对同一 IP + 账号连续 5 次失败锁定 60 秒；同一 IP 10 分钟内最多提交 5 次注册
- 注册与个人信息：登录页可自助注册——所有自助注册账号（学生/教师）均进入管理员待审核队列（通过/拒绝在「用户管理」页），审核前登录会被拦截并提示；管理员新增或批量导入的账号直接生效；所有角色可在侧边栏修改姓名（学生含班级），管理员也可编辑任意用户的姓名/班级
- 编程题与自动判题：新增编程题型（JavaScript / Python），教师出题时设代码模板、参考代码与多条测试用例（标准输入 → 期望输出，期望输出对学生不可见）；学生答题页是代码编辑器，可点「运行测试」自查（不计分）；交卷时服务端逐条用例在本机子进程中运行学生代码（每条限时 3 秒、输出限长），按通过比例给分，逐题回顾与错题本都展示每条用例的输入/期望/实际与状态（通过/输出不符/运行错误/超时）；错题本可改代码重练。注意：判题为单机演示级实现，未做系统级沙箱隔离，请勿在公网环境开放
- 教学分析与监考（v1.6）：统计页新增「知识点掌握度」（按得分率从弱到强排序，一眼看出全班最薄弱的知识点）与「班级成绩对比」（人数/平均分/最高分/及格率）；考试管理对进行中的考试提供「监考」台：已进入/答题中/已交卷/未进入四项计数、每名考生的答题进度与切屏次数，每 5 秒自动刷新；成绩明细每行可「重置答卷」删除单个学生的答卷供其补考；试卷与考试均可一键「复制」（考试副本自动排到明天、状态未开始，可再编辑）
- 学生自主练习（v1.6）：学生端「自主练习」按题型/知识点随机抽题（不含简答题），整组作答后统一提交、即时判分并显示正确答案与解析，编程题同样支持运行测试与判题；练习成绩不计入正式考试统计
- AI 模型接口：管理员在「AI 接口设置」页接入任意 OpenAI 兼容接口（Base URL + 模型名 + API Key，如 DeepSeek、通义千问、Kimi、智谱，或本机 Ollama http://localhost:11434/v1），可一键测试连接；开启后三处可用：①教师批改简答题时「AI 辅助批改」按参考答案与评分要点给出建议分与评语，教师确认/修改后保存才生效；②题库「AI 生成题目」按主题/题型/难度生成草稿，打开编辑窗人工核对后入库；③答卷回顾每题「AI 讲解」结合学生答案讲错因。未启用时所有 AI 入口自动隐藏，其余功能不受影响；API Key 只存本机数据库，接口返回异常时前端会给出明确原因
- 管理员删除用户：已有答卷记录的用户禁止删除，防止成绩数据丢失
- 4.3 组卷：手动勾选 + 规则随机抽题（题型×难度数量），抽题结果可逐题替换、改分，已选题目可 ↑↓ 调序，总分自动汇总，试卷可预览整卷、可再编辑（被进行中/已结束考试引用的试卷除外）
- 4.4 考试管理：设定试卷、时间窗口、时长、是否展示答案；可限定参考班级（不选则全部学生可见）并设置可选考试口令（首次进入需校验、连续输错 10 次锁定 60 秒、学生端不下发口令明文）；状态按时间自动流转；列表展示参考/交卷人数与平均分；未开考的考试可编辑（改名、换卷、改时间/时长、班级范围与口令）或删除
- 4.5 在线考试：答题卡（已答/标记/跳转）、倒计时（剩余 5 分钟变红提醒）、标记本题、答案实时保存（刷新不丢）、交卷二次确认（提示未答题数）、到时自动交卷
- 4.5 防作弊（Demo 级）：记录切屏/失焦次数，超过 3 次在教师统计与学生成绩旁标注提醒
- 4.6 成绩统计：参考人数、平均分、最高/最低分、及格率、分数段分布图、每题正确率、错题排行 Top 10、成绩明细、CSV 导出
- 4.6 学生端：我的成绩（含排名）、逐题回顾（按教师开关决定是否展示正确答案与解析）、站内开考提醒（开考前 30 分钟内于「参加考试」页顶部提示剩余时间，每分钟刷新，开考后自动消失）
- 4.7 管理员：数据概览、用户管理（新增/删除/批量导入学生）、班级增删、重置学生密码、数据备份与恢复；另全角色自助修改密码、学生错题本、试卷打印

## 与 PRD 技术方案的差异（Demo 期取舍）

PRD 建议 Vue 3 + Spring Boot/Node.js + MySQL + Docker Compose。本 Demo 为保证「单机零依赖、拷过去就能跑」，做了等效简化：

- 后端：Node.js 原生实现（无第三方包），单文件 `server.js`
- 前端：原生单页应用（`public/`），无构建步骤、无 CDN，断网可用
- 存储：本地 JSON 文件（`data/db.json`）代替 MySQL，数据模型字段与 PRD 第 6 节一致，正式版可平滑迁移
