# 站内考试提醒设计

## 目标

在学生端提供清晰、无需外部服务的即将开考提醒，避免学生错过考试。

## 行为

- 学生打开“参加考试”页时，筛选状态为“未开始”、距离开考时间大于 0 且不超过 30 分钟的考试。
- 学生已交卷的考试不显示提醒。
- 提醒位于考试列表顶部，显示考试名称、开考时间及剩余时间；没有符合条件的考试时不显示提醒区。
- 考试开始后，提醒自动消失；常规考试卡片与既有“开始考试”操作保持不变。
- 学生停留在考试列表时，每分钟重新读取考试列表并刷新提醒状态。离开该页面时停止轮询。
- 复用 `/api/exams` 返回的考试时间和个人答卷状态，不新增数据库字段、服务端定时任务、浏览器权限或第三方服务。

## 实现边界

提醒基于服务端返回的考试窗口与现有 `mySheet` 状态；剩余时间在浏览器按本地时间计算。此功能是站内页面提示，不承诺页面关闭时的通知送达。

## 验收标准

1. 31 分钟后开考的考试不显示提醒。
2. 30 分钟内尚未开考且未交卷的考试显示提醒和正确的剩余时间。
3. 已交卷的考试不显示提醒。
4. 开考后提醒在下一次刷新周期内消失，考试卡片状态及操作正确。
5. 离开学生考试列表后，不再发起定时刷新请求。
6. 教师端、题库、判分和已有考试操作不受影响。
