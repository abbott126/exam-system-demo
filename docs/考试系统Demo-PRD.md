## 1. 背景与目标

面向课堂演示与小规模单机考试的完整闭环系统。核心目标是「拷过去就能跑」：

1. 教师建题、组卷、发布考试；
2. 学生在浏览器中答题、交卷；
3. 服务端自动判分（客观题与编程题），主观题进入人工阅卷；
4. 教师查看统计、导出成绩，管理员管理账号与数据。

约束优先级：单机零依赖 > 断网可用 > 功能完整 > 界面美观。

|---|---|---|---|
| 题库增删改查（仅本人创建） | 是 | 否 | 否 |
| 组卷、复制试卷、打印试卷 | 是（仅本人） | 否 | 否 |
| 发布/编辑/停止/归档考试 | 是（仅本人） | 否 | 否 |
| 参加考试、交卷、查看本人成绩 | 否 | 是（参考范围内） | 否 |
| 查看本场考试统计、监考、导出 | 是（仅本人） | 否 | 否 |
| 错题本、自主练习 | 否 | 是 | 否 |
| 用户/班级管理、备份恢复 | 否 | 否 | 是 |
| AI 接口配置 | 否 | 否 | 是 |

服务端对每个接口做角色校验；学生答题接口不下发正确答案；教师只能访问自己创建的题目、试卷、考试。

## 3. 范围

### 3.1 纳入范围

- 账号：登录、自助注册（需审核）、角色权限、改密、改资料；
- 题库：六种题型、筛选、CSV 导入导出、AI 生成草稿；
- 组卷：手动选题、规则随机、换题、调序、改分、复制、打印；
- 考试：时间窗口、时长、参考班级、考试口令、切屏上限、答案展示开关、归档、停止、复制；
- 答题：答题卡、倒计时、标记、自动保存、断线恢复、到时/切屏/教师停止自动交卷；
- 判分：客观题自动判分、编程题按用例比例判分、简答题人工阅卷（可选 AI 建议）；
- 成绩：学生成绩与排名、逐题回顾、教师统计、CSV 导出、监考台；
- 学习：错题本、错题重练、自主练习；
- 管理：数据概览、用户/班级管理、备份恢复、AI 接口设置。

### 3.2 不纳入范围

- 人脸核验、双机位监考、摄像头监控；
- 教务系统对接、统一身份认证；
- 千人级高并发与分布式部署；
- 公网级判题沙箱（当前仅进程级隔离）；
- 邮件/短信/微信通知；
- 多租户、多机构隔离。

## 4. 术语

| 术语 | 含义 |
|---|---|
| 题目 | 题库中的最小单位，含题型、题干、答案、解析、分值、难度、知识点 |
| 试卷 | 题目与分值的组合，有总分 |
| 考试 | 试卷在时间窗口内的一次发布，含时长、范围、口令等规则 |
| 答卷 | 一名学生对一场考试的一次作答记录 |
| 答卷明细 | 答卷中每道题的得分、对错、评语、判题结果 |
| 待批改 | 简答题尚未人工给分，整卷分数为暂定 |
| 切屏 | 答题页失去焦点或切换窗口，计入 `switchCount` |
| 参考范围 | 考试允许参加的学生班级集合，空表示全部学生 |
| 考试口令 | 学生首次进入考试时需要输入的可选口令 |

## 5. 功能需求

### FR-1 账号与认证

- FR-1.1 使用「账号 + 密码」登录，成功后返回 Bearer Token 与用户信息；Token 存于服务端内存。
- FR-1.2 角色固定为 `admin` / `teacher` / `student`。
- FR-1.3 自助注册仅允许学生/教师；注册后状态为 `pending`，管理员审核通过后方可登录；管理员新增或批量导入的账号直接生效。
- FR-1.4 同一 IP + 账号连续登录失败 5 次，锁定 60 秒；同一 IP 10 分钟内最多提交 5 次注册。
- FR-1.5 所有角色可修改本人密码（校验旧密码）与姓名；学生可改班级。
- FR-1.6 管理员可编辑任意用户资料、重置密码、删除用户；已有答卷记录的用户禁止删除。

### FR-2 题库管理

- FR-2.1 支持题型：单选 `single`、多选 `multi`、判断 `judge`、填空 `fill`、简答 `essay`、编程 `code`。
- FR-2.2 题目字段：题干、选项、答案、解析、分值、难度（易/中/难）、知识点标签、科目、创建人。
- FR-2.3 单选答案必须落在选项中；多选答案非空且均落在选项中；判断答案只能是 `true`/`false`；填空答案按空给出，支持 `|` 分隔等价答案；简答必须有参考答案。
- FR-2.4 编程题必须选择 `javascript` 或 `python`，至少 1 条、最多 20 条测试用例；每条用例包含标准输入与期望输出，期望输出对学生不可见。
- FR-2.5 列表支持按题型、难度、关键词筛选。
- FR-2.6 支持 CSV 批量导入（单次最多 500 行，返回逐行错误）与 CSV 导出。
- FR-2.7 题目被试卷引用时禁止删除。
- FR-2.8 可选 AI 生成题目草稿，教师核对后入库。

### FR-3 组卷

- FR-3.1 手动选题并逐题设置分值，总分自动汇总。
- FR-3.2 规则随机抽题：按「题型 × 难度 × 数量」抽取，题量不足时明确报错。
- FR-3.3 支持逐题替换、上移/下移调序、预览整卷、复制试卷。
- FR-3.4 试卷被进行中或已结束的考试引用时禁止修改；被任意考试引用时禁止删除。
- FR-3.5 支持生成学生版（无答案）与教师版（含解析）打印页。

### FR-4 考试发布与管理

- FR-4.1 发布字段：名称、试卷、开始时间、结束时间、时长（正整数分钟）、切屏上限（0 为不限）、是否展示答案、备注、参考班级、考试口令（可选，最长 32 字符）。
- FR-4.2 校验：结束时间必须晚于开始时间；参考班级必须存在；试卷必须属于当前教师。
- FR-4.3 状态按时间自动流转：未开始 / 进行中 / 已结束；教师可提前停止，停止后状态为已停止。
- FR-4.4 仅未开始的考试可编辑；支持复制（副本排到次日、未开始）、归档/取消归档。
- FR-4.5 教师列表仅显示本人考试，可按归档筛选；学生列表仅显示未归档且自己在参考范围内的考试。

### FR-5 在线答题

- FR-5.1 学生进入考试时校验参考范围、考试状态、是否已停止；首次进入且设置了口令时校验口令，连续输错 10 次锁定 60 秒。
- FR-5.2 首次进入创建答卷；未交卷再次进入复用原答卷并恢复答案。
- FR-5.3 截止时间 = min(开始作答时间 + 考试时长, 考试结束时间)。
- FR-5.4 答题接口返回题目、分值、填空空数、编程语言/模板/用例数量，不返回正确答案。
- FR-5.5 答案实时保存（`progress` 接口），刷新/断线后可恢复；服务端在保存与交卷时兜底校验超时、停止、切屏超限。
- FR-5.6 切屏次数超过上限自动交卷，交卷原因记为 `switch`；到时记 `timeout`；教师停止记 `stopped`；主动交卷记 `manual`。
- FR-5.7 前端提供答题卡、已答/标记状态、题目跳转、剩余 5 分钟提醒、交卷二次确认（提示未答题数）。
- FR-5.8 编程题可「运行测试」自查，结果不计入分数；正式判分在交卷时进行。

### FR-6 判分与阅卷

- FR-6.1 单选/判断：答案完全一致得满分，否则 0 分。
- FR-6.2 多选：全对满分；漏选按选中正确项比例给分；含任一错选 0 分。
- FR-6.3 填空：去首尾空格后精确匹配；多空按空平均给分；支持 `|` 分隔等价答案。
- FR-6.4 简答：交卷后标记为待批改，整卷分数暂定；教师逐题给分并写评语后总分自动更新。
- FR-6.5 编程：逐条用例在子进程中运行，通过用例数 ÷ 总用例数 × 本题分值；状态包括通过、输出不符、运行错误、超时、空代码。
- FR-6.6 判题限制：单用例限时 3 秒；单用例输出上限 64KB；代码上限 20000 字符；超时或超长输出按进程组整体终止。
- FR-6.7 判题隔离：清空继承环境变量、在系统临时目录运行、独立进程组、Node 限堆 128MB、Python 使用 `-I -B` 隔离模式。
- FR-6.8 教师可重置单个学生的答卷用于补考；已有答卷记录受保护。
- FR-6.9 可选 AI 辅助批改简答题，AI 仅给建议分与评语，教师确认后才生效。

### FR-7 成绩与统计

- FR-7.1 学生可查看本人成绩、排名与逐题回顾；是否展示正确答案与解析由考试的 `showAnswer` 决定。
- FR-7.2 教师统计包含：参考人数、交卷人数、平均分、最高/最低分、及格率、分数段分布、每题正确率、错题 Top 10、成绩明细、知识点掌握度、班级对比。
- FR-7.3 及格率与分数段按得分率折算，兼容非 100 分试卷。
- FR-7.4 成绩明细支持 CSV 导出。
- FR-7.5 监考台展示已进入/答题中/已交卷/未进入计数、每名考生进度与切屏次数，前端每 5 秒刷新。
- FR-7.6 错题本自动收录答错或未满分题目（仅限开启答案展示的考试），支持重练与手动移出。

### FR-8 自主练习

- FR-8.1 学生按题型/知识点随机抽题，不含简答题。
- FR-8.2 整组提交后即时判分并展示答案与解析；编程题支持运行测试与判题。
- FR-8.3 练习成绩不计入正式考试统计。

### FR-9 管理员

- FR-9.1 数据概览：用户、班级、题目、试卷、考试、答卷数量。
- FR-9.2 用户管理：列表、新增、编辑、删除、重置密码、审核注册、CSV 批量导入学生。
- FR-9.3 班级管理：新增、删除（删除前校验是否仍被学生使用）。
- FR-9.4 数据备份：导出全量 JSON；从备份恢复后要求重新登录。
- FR-9.5 AI 接口设置：Base URL、模型名、API Key，可测试连接；未启用时前端隐藏 AI 入口。

### FR-10 AI 能力（可选）

- FR-10.1 兼容任意 OpenAI Chat Completions 接口，调用超时 45 秒。
- FR-10.2 三处使用：简答批改建议、按主题/题型/难度生成题目草稿、答卷逐题讲解。
- FR-10.3 API Key 仅保存在本机数据库，不返回给前端；接口异常时返回明确错误原因。

## 6. 非功能需求

- NFR-1 零第三方依赖：仅使用 Node.js 内置模块，无构建步骤、无 CDN、无外链字体/图片。
- NFR-2 运行环境：Node.js 18 及以上；核心考试流程断网可用；Python 判题需本机 `python3`。
- NFR-3 存储：单机 JSON 文件；首次启动自动生成种子数据；支持 Docker 命名卷持久化。
- NFR-4 时区：考试时间窗口按 `Asia/Shanghai` 本地时间解释。
- NFR-5 界面：原生单页应用，桌面与移动端自适应（375px 起无横向溢出）。
- NFR-6 安全（Demo 级）：密码加盐哈希存储；Token 仅存内存；接口按角色隔离；登录/口令/注册限流；学生接口不下发答案。
- NFR-7 性能：面向单机课堂演示，不承诺高并发；每次写操作落盘 JSON。
- NFR-8 可维护性：后端单文件 `server.js`，前端 `public/`；接口与判分逻辑保持可读、可测试。

## 10. 技术架构与运行约束

- 后端：`server.js` 单文件，Node 原生 `http`；静态资源由同一服务提供。
- 前端：`public/index.html` + `style.css` + `app.js`，原生 SPA，无框架、无构建。
- 环境变量：`PORT`（默认 3000）、`DATA_DIR`（默认 `data/`，测试用临时目录隔离）。
- 数据文件：`DATA_DIR/db.json`；首次启动自动写入种子数据。
- 容器：`Dockerfile` 基于 `node:22-alpine` 并内置 `python3`；`docker-compose.yml` 使用命名卷持久化。

## 11. 已知限制

- 判题未做系统级沙箱，学生代码仍可访问网络与文件系统，禁止直接部署到公网。
- Token 存于内存，服务重启后需重新登录。
- JSON 单文件存储在写入时全量落盘，不适合高并发或多实例。
- 密码哈希使用固定盐，仅适用于演示环境。
- 无操作审计日志、无邮件/短信通知、无教务系统对接。
